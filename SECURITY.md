# Security

## Reporting a vulnerability

Please don't open a public issue. Write to [contact@metrikdelta.com](mailto:contact@metrikdelta.com) with "Security" in the subject, describing the problem and how to reproduce it.

You'll get an answer within a week. Once it's fixed, you're credited in the commit if you wish.

## Scope

- The website, [metrikdelta.com](https://metrikdelta.com), and its API.
- The code in this repository.

The site has no accounts and stores no personal data of its own (see the [Legal](https://metrikdelta.com/legal) page). Problems in the data sources themselves (FastF1, OpenF1, Jolpica) are for their maintainers.

Only the latest version, the one deployed from `main`, is supported.
